# Contributing

Install `.[dev]`, run `ruff check src tests scripts` and `pytest -q`, and exercise relevant CLI behavior. Include source locators and conditions for scientific changes. Add meaningful tests when calculations, units, parsers, bookkeeping or validation rules change.

Keep generated/synthetic results separate from computed PFAS results and published reference data. Record raw-output provenance, pseudopotentials, convergence and transition-state checks. Do not claim a catalyst ranking or accuracy based on fixture values or an incomplete comparison. Benchmark policy changes require justification before examining held-out results.

Preserve upstream attribution and licenses. No author affiliations, credentials, laboratory history, GitHub identity, or research accomplishments should be inferred from the owner label. AI-assisted code still needs scientific review.
