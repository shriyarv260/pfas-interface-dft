# External pseudopotentials

Place reviewed QE UPF files here, or set an absolute `pseudo_dir`. The example names `C.UPF`, `F.UPF`, etc. are placeholders; replace them with exact chosen filenames. Match exchange-correlation, scalar/fully relativistic treatment, valence and cutoff requirements consistently. Record source URLs, licenses and SHA-256 values. The execution manifest hashes files actually used. No pseudopotential is bundled or certified by this repository.
